# TV Around the World — استوديو البرامج

موقع تفاعلي لثاني ثانوي، الصفحتان 54–55، مبني على الصور المرفقة والمواد المعدة للحصة.

## النشر على GitHub Pages

1. فك ضغط ملف TV-Studio-GitHub-Pages.zip على جهازك.
2. أنشئ مستودعًا جديدًا في GitHub، مثل `tv-around-the-world`.
3. ارفع **محتويات الملف بعد فك الضغط** إلى جذر المستودع. يجب أن يكون `index.html` ظاهرًا مباشرة بجانب `app.js` و`style.css` و`lesson.js` ومجلدي `assets` و`files`؛ لا ترفع ملف ZIP وحده، ولا تضع الملفات داخل مجلد إضافي.
4. احفظ الملفات عبر Commit changes.
5. افتح Settings ثم Pages. في Source اختر Deploy from a branch.
6. اختر فرع main ومجلد /(root)، ثم Save.
7. انتظر اكتمال النشر، وافتح الرابط الذي يظهر في صفحة Pages. لم يُنشر هذا الملف نيابة عنك؛ لا يوجد رابط حي قبل إتمام هذه الخطوات.

مرجع GitHub الرسمي:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## تشغيل الحصة

- البداية: التمهيد والأهداف.
- البرامج الستة: الصور، النوع، الفكرة المبسطة، النص الأصلي والدليل.
- الكلمات: اضغط لكشف المعنى والمثال.
- استمع واكتشف: قراءة المعلم، أو قراءة آلية من الجهاز؛ القراءة الآلية للتبسيط وليست تسجيل الكتاب الرسمي.
- تحدّي الاستوديو: مطابقة + مؤقت 6 دقائق + لوحة نقاط 4 فرق. يضيف المعلم النقاط وفق صحة الإجابات والأدلة والمشاركة.
- Quick Check: أسئلة الكتاب A وB كاملة وتصحيح فوري. في أول سؤال مفردات يقبل air وbroadcast بأي ترتيب، ولا يحتسب تكرار الكلمة كإجابتين صحيحتين.
- برنامجنا: كتابة عنوان ونوع ووصف مع معاينة مباشرة وتنزيل نص البطاقة.
- بطاقة الخروج: تصحيح 4 اختيارات؛ تقييم الكتابة للمعلم من 3. لا يُستخدم عد الكلمات أو اكتمال الحقول لمنح درجة لغوية تلقائية.
- الكتاب: صورتا الصفحتين الأصليتان.
- دليل المعلم: خطة الدقائق وملفات PDF وطريقة مسح بيانات الجهاز.

## طريقة الحفظ

يعمل الموقع دون حسابات أو خادم خلفي. تحفظ الإجابات وبطاقة البرنامج والنقاط في متصفح الجهاز باستخدام localStorage. ليست هناك مزامنة أو لوحة نتائج مشتركة، ولا إرسال تلقائي للمعلم. يُنزّل الطالب ملف الإجابات ويسلمه بالطريقة التي يحددها المعلم. مسح بيانات المتصفح يمسح الحفظ المحلي. إذا كان التخزين محظورًا، استخدم تنزيل البطاقة.

دليل المعلم أداة عرض وليست منطقة محمية بكلمة مرور؛ الملفات والإجابات ضمن الموقع الثابت. يناسب التدريب الصفي وليس اختبارًا سريًا عالي المخاطر.

## التجهيز والبدائل

احفظ الملفات محليًا قبل الحصة. يمكن فتح index.html محليًا في متصفح يدعم تشغيل الملفات؛ الأفضل رابط GitHub Pages على الجوال والآيباد. لا توجد خطوط أو مكتبات أو صور تُحمّل من مواقع خارجية. توفر صوت الجهاز وجودته يتوقفان على المتصفح والأصوات المثبتة، وقد يحتاجان إلى الإنترنت؛ قراءة المعلم هي البديل.

جميع إحصاءات البرامج ومواعيدها وفق النص المرفق، وليست معلومات حالية متحققة. الأنشطة والأمثلة المبسطة من إعدادنا. الأصول الأصلية للكتاب محفوظة دون إعادة رسم.

## الملفات

- index.html: الواجهة.
- style.css: التنسيق المتجاوب ووضع الطباعة.
- lesson.js: محتوى الدرس.
- app.js: التفاعل والتصحيح والحفظ.
- assets/: الصور المحلية.
- files/: دليل المعلم، ورقة العمل، مفتاح الإجابة.

لا توجد خطوة تثبيت أو بناء مطلوبة.
